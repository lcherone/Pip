# The Pip brand kit 🐾

**Pip — a little golden company for your Mac.**

Pip’s identity comes from the character already in the app: golden fur, cream highlights, expressive ears, gentle curiosity, and little bursts of play. The branding adds a name treatment, a paw mark, a README banner, and a consistent voice around that puppy.

This kit covers documentation and presentation. It does not change the application icon, tray icon, interface, or runtime behaviour.

## The words on the collar

| Role | Copy |
| --- | --- |

| Main descriptor | **A living desktop puppy for macOS.** |
| Welcome line | **A little golden company for your Mac.** |

| Short description | **A golden desktop puppy who explores your windows, naps beside your work, and saves you a wag. Optional Codex assistance when you need a paw.** |
| README sign-off | **“That one got the whole tail.”** |

Write **Pip**, with one capital P. He is a character name, not an acronym. Use “he” in character writing, following the app’s existing copy. Explain the app plainly before adding puppy wordplay.

## His voice

**Warm, curious, concrete, and a little playful.** Pip is a friendly presence with a small-dog point of view. He can be funny without turning every technical sentence into a dog joke.

Keep everyday dialogue short. Let ears, paws, and tail do some of the talking. Give technical answers the detail they need; the puppy voice should never obscure a result or a permission request.

| Moment | Voice example | Status |
| --- | --- | --- |
| Hello | “Hi. I saved you a wag.” | Existing local reply. |
| Affection | “That one got the whole tail.” | Existing local reply. |
| Copied success | “That deserves a tail wag!” | Existing local reply. |
| Copied frustration | “That looks like a tricky bit. I'm here with you.” | Existing local reply. |
| Sleepy | “I could curl up. Wake me if you need a paw.” | Existing local reply. |
| Permission | “May I inspect this project?” followed by the exact scope. | Editorial example; not promised UI copy. |

Avoid baby talk, constant barking, guilt about leaving him alone, or claims that Pip understands text he has not received. Describe Codex-backed work as optional and permission-controlled. Never turn “cute” into a claim of privacy, safety, or completed work.

The new SVGs are editable vector artwork with no scripts, external fonts, linked images, or remote dependencies. The banner’s puppy is a brand illustration, not a screenshot of the running app. The live puppy continues to be drawn by the Canvas renderer.

Keep clear space around the paw mark. Preserve its square aspect ratio and the banner’s wide aspect ratio. Do not stretch Pip, recolour his fur arbitrarily, or present the paw emblem as a new application icon without a separate implementation change.

Use rounded, friendly typography for presentation when available, with normal system fallbacks. The SVG wordmark uses a local rounded/system font stack and remains live text. Keep README prose as native Markdown so it stays readable on narrow screens and with assistive technology.
